# Enllaç punt a punt

Simulador d'enllaços de microones per al mòdul 0365 – Radiocomunicacions:
balanç de potències, antenes i orientació, i visibilitat directa amb la 1a zona de Fresnel
sobre un perfil real del terreny.

`index.html` és una pàgina autònoma generada amb `npm run build` a partir del codi font del
projecte (src/, proves i script de construcció), que es manté a part.
Inclou Leaflet 1.9.4 (BSD-2-Clause).
